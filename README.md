# Главная ЖН

Автономный веб-прототип анимации главного экрана A101. Проект служит исполняемым визуальным эталоном для интеграции в production-сайт.

Подробная спецификация для фронтенд-разработчика: [FRONTEND_HANDOFF.md](./FRONTEND_HANDOFF.md).

## Запуск

Требуется Node.js 18 или новее. Установка зависимостей не нужна.

```bash
npm start
```

Открыть: <http://127.0.0.1:4173>

## Состав проекта

- `index.html` — семантическая разметка всех экранов и интерактивных блоков;
- `styles.css` — визуальные состояния, анимации и адаптивная геометрия;
- `app.js` — таймлайн, физика курсора, параллакс и управление состояниями;
- `assets/` — все изображения и SVG-иконки без временных Figma URL;
- `server.mjs` — только локальный статический сервер, не production-реализация.

## Управление прототипом

- интро запускается автоматически;
- кнопка «Пропустить», `Escape` или клик по свободной области видео открывают финальный экран;
- `R` или «Повторить интро» перезапускают сценарий;
- при `prefers-reduced-motion: reduce` сразу показывается финальный экран.
